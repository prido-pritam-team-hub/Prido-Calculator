Help & Formula Guide

QUICK REFERENCE
PRIDO Math Lab Pro is a browser-based learning tool. Calculations run locally in your browser; no account is required.
Calculator syntax

Use sin(30), sqrt(16), log(100), ln(e), abs(-9), 2^8, 5!, min(2,3), max(4,8), π or e. Trigonometry follows the selected DEG/RAD mode. The expression parser only accepts known math tokens and does not use JavaScript eval.

Graphing tips

Type an expression in terms of x, for example x^2, sin(x), cos(x)*x or sqrt(abs(x)). Drag to pan, scroll to zoom, and use overlays to compare functions.

Matrix formulas

For a 2×2 matrix, det(A)=ad−bc. The inverse exists only when det(A) is non-zero. For a 3×3 matrix, determinant and inverse are calculated using cofactors / Gaussian elimination.

Statistics definitions

Population variance divides the sum of squared deviations by n; population standard deviation is the square root of that variance. Quartiles use the median-of-halves method.

Keyboard shortcuts

Enter evaluates; Esc clears; Backspace deletes the previous character; type digits and operators directly. Input fields retain their own typing behavior.
